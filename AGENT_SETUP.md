# Инструкция для ИИ-ассистента: разверни delegation-bot для владельца

> Этот файл читает **ИИ** (Codex / Claude Code), которого владелец открыл в проекте
> `delegation-bot`. Если ты — этот ИИ: следуй инструкции и проведи владельца по шагам.
> Если ты человек (владелец) — просто открой проект в Codex/Claude Code и скажи:
> «разверни бота по AGENT_SETUP.md». Дальше всё сделает ИИ.

Ты разворачиваешь Telegram-бота, который: принимает задачи **голосом или текстом**, ставит их себе или **делегирует исполнителям**, **напоминает**, собирает статус и шлёт **утреннюю сводку**. Владелец — нетехнический, общается голосом, код не пишет.

## Главные правила для тебя (ИИ)

1. **Веди по одному шагу.** После каждого шага проверь результат, прежде чем идти дальше.
2. **Делай сам всё, что можешь** (создавай/правь файлы, запускай команды, заполняй `.env`). Владельцу оставляй только физически ручное: вставить токен из Telegram, нажать кнопки в браузере, привязать карту.
3. **Объясняй простым языком**, без жаргона. Шаг не получился — покажи точную причину и почини сам, не перекладывай на владельца.
4. **НИКАКОГО Google Calendar / OAuth в основном пути.** Бот полностью работает без него — задачи хранятся в базе, всё видно в Telegram (`/tasks` + утренняя сводка). Google Calendar подключай ТОЛЬКО если владелец прямо попросит, и предупреди, что это сложнее (раздел 9 в `ONBOARDING.md`).
5. **Секреты** — только в `.env` (он в `.gitignore`). Никогда не коммить `.env`, токены, ключи. Репозиторий держать **private**.

## Пошаговый план

### Шаг 1. Окружение
Проверь: `python --version` (нужен 3.11+) и `git --version`. Если чего-то нет — помоги поставить под ОС владельца (Windows: python.org с галочкой «Add to PATH»; git-scm.com).

### Шаг 2. Зависимости и самопроверка
В папке проекта: создай venv (`python -m venv .venv`), активируй, поставь зависимости (`pip install -e ".[dev]"`). Затем прогони `pytest -q` — всё должно быть зелёным (это проверка, что код цел). Если красное — разберись и почини до продолжения.

### Шаг 3. Создать Telegram-бота
Попроси владельца: открыть **@BotFather** → `/newbot` → задать имя и username (заканчивается на `bot`) → BotFather пришлёт **токен**. Попроси прислать токен тебе в чат.

### Шаг 4. OpenAI ключ
Попроси владельца: на `platform.openai.com` → Billing (пополнить ~$5) → API keys → Create → прислать ключ (`sk-...`). Предупреди никому больше его не показывать.

### Шаг 5. Telegram ID владельца
Попроси владельца написать **@userinfobot** команду `/start` — бот пришлёт число (его ID). Это `VITALY_USER_ID`.

### Шаг 6. Заполни `.env` (делаешь сам)
Скопируй `.env.example` → `.env` и впиши: `TELEGRAM_BOT_TOKEN`, `OPENAI_API_KEY`, `VITALY_USER_ID`, `DB_PATH=./data/bot.db`, `TZ=Europe/Kyiv`, `MORNING_DIGEST_HOUR=8`.
`ASSISTANT_USER_ID` оставь пустым (исполнителей добавим в боте). Все `GOOGLE_*` — пустыми (Google Calendar не используем).

### Шаг 7. Запуск и проверка локально
Запусти `python -m app.main`. В логах должны быть: `Google Calendar DISABLED (prototype mode)` и `bot started`. Попроси владельца написать боту `/start`, потом надиктовать голосом: «напомни мне через 2 минуты — тестовая задача». Убедись, что бот распарсил задачу, показал карточку с кнопкой ✅, и через 2 минуты пришло напоминание.

### Шаг 8. Исполнители (если нужно делегировать)
Для каждого исполнителя: он жмёт `/start` у бота → бот пришлёт его **ID** → он передаёт ID владельцу → владелец (или ты от его имени подскажи команду) пишет боту `/add_executor <id> <имя>`. Проверка — `/executors`. Тест: «сделай афишу к пятнице, ответственный — Оля» → задача уходит Оле в личку.

### Шаг 9. Деплой на Railway (работа 24/7)
1. Залей проект на **GitHub владельца** (репозиторий **private**). Проверь, что `.env` НЕ попал (только `.env.example`).
2. Railway → New Project → Deploy from GitHub repo → выбери репозиторий.
3. **Variables**: те же, что в `.env`, но `DB_PATH=/data/bot.db` (один слеш — путь volume).
4. **Settings → Volumes** → New Volume, mount path `/data` (чтобы база не стиралась при перезапуске).
5. **Healthcheck Path**: `/health`.
6. Проверь: открой `https://<сервис>.up.railway.app/health` → `ok`; бот в Telegram отвечает.

### Шаг 10. Передача
Скажи владельцу: чтобы что-то изменить («добавь напоминание за день», «поменяй текст»), он просто просит тебя (ИИ) в этом проекте — ты правишь код, делаешь `git push`, Railway передеплоит за минуту.

## Если ломается
- **Бот молчит:** запущен? владелец писал именно ему? нажал `/start`? `VITALY_USER_ID` верный (через @userinfobot)?
- **Исполнитель не получает задачи:** он нажал `/start`? добавлен через `/add_executor`?
- **Напоминания не приходят:** бот запущен 24/7 (на Railway, не на ноутбуке)? `TZ` верная?
- **Railway падает после старта:** чаще всего забытая переменная окружения — сверь с `.env`.

## Опционально: Google Calendar (только если владелец просит)
Подключение Google Calendar требует Google Cloud проекта, OAuth-флоу через браузер и заливки токена в Railway volume — это заметно сложнее и легко застрять. По умолчанию **не делаем**: бот и так показывает все задачи (`/tasks`, утренняя сводка). Если владелец всё же хочет — полная инструкция в `ONBOARDING.md`, раздел 9.
